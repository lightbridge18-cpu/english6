# pip english · 六年级英语闯关站 v3 · PEP Grade 6

在线使用：<https://lightbridge18-cpu.github.io/english6/>

给六年级孩子用的英语同步练习站，内容对应 **人教PEP《英语》六年级上册（2026 新版）** 和 **六年级下册（2027 春）**。v3 按 Duolingo 的玩法全面重做：蜿蜒的学习路径、吉祥物「皮皮」、连胜 / 宝石 / 爱心 / 排行榜 / 任务 / 商店。

## v3 新玩法

- **课程切换**：顶栏左侧的课本按钮（📘 六上 / 📗 六下）。课本列表来自 `data/books.json`，每本书的进度分开保存。
- **学习路径**：每个单元一条蛇形路径 + 彩色单元横幅（📖 GUIDEBOOK 单元要点）；圆形 3D 关卡按钮，当前关卡跳动并显示 START，完成后变金色并显示等级；关卡之间有宝箱（送宝石），单元末尾是 🏆 单元挑战。默认按顺序解锁，可「跳到这里」做测试跳级；家长中心可一键解锁全部。
- **题型**：图片选词、点击配对（5 对）、单词块翻译（中→英 / 英→中）、听音点词（可切换键盘输入，含 🐢 慢速）、选词填空、完成对话、跟读口语（语音识别逐词高亮）、选择、听力、拼写、连词成句。可以「现在不方便听 / 说」跳过 1 小时。
- **反馈**：底部 CHECK 按钮→绿色 / 红色反馈面板（正确答案 + 解析 + 朗读），连对进度条发光，WebAudio 生成的音效，答错抖动，完成撒彩带，手机振动；课程完成页（经验、正确率、用时、连击奖励）和连胜页（本周日历）。
- **游戏系统**：每日经验目标（10/20/30/50）、爱心（5 颗，每 30 分钟恢复 1 颗，练习赚回，或用宝石补满）、宝石、商店（爱心补满、连胜冻结、双倍经验、皮皮装扮、主题）、每日 3 个任务 + 月度徽章、每周联赛（青铜→钻石，本地模拟的练习伙伴，前 5 晋级后 5 降级）、成就。
- **练习中心**：错题复习（间隔重复）、听力练习、口语练习、综合练习、单词练习、课文听读、故事、单词表。
- **家长中心**：学习时长上限、PIN、导出 / 导入（兼容 v2 备份）、解锁全部、无限爱心。
- 进度保存在本浏览器 `localStorage` 的 `e6.v3`（首次打开会自动把旧版 `e6.v2` 的进度迁移进六上，旧数据保留不动）。

## 目录

```
index.html          页面外壳
css/style.css       样式（Nunito 字体加载不了时自动用苹方 / 微软雅黑）
js/app.js           全部交互逻辑（纯 JS，无需构建）
data/books.json     课本清单（id、标题、数据文件）
data/book.json/.js  六年级上册数据（id: book）
data/g6down.json/.js 六年级下册数据（id: g6down）
tools/              生成上册数据用的脚本和内容源文件（Python）
```

加新课本：把同结构的 JSON 放进 `data/`，在 `data/books.json` 里加一项（`ready: true` 直接显示；不写 `ready` 时，打开课程菜单才探测文件是否存在）。

数据结构（`data/book.json`）：`units[]` 每个单元含 `words`（单词、音标、中文、课本页码、`req` 是否黑体“会用”词、`lvl2` 课标二级词、`past` 过去式）、`passages`（课文逐句：说话人 / 英文 / 中文）、`lessons`（讲解 `explain`、重点句 `key`、题目 `questions`）、`stories`、`song`、`expressions`（附录 4）、`grammar`；另有 `irregular`（附录 5）。

重新生成数据：在 `tools/` 下运行 `python3 build.py ..`（需要 pymupdf 和课本 PDF，路径见脚本）。只改题目或讲解时，编辑 `tools/content/u*.py` 后重新生成即可。
