# 六上英语闯关站 v2 · PEP Grade 6 Book 1 (2026)

在线使用：<https://lightbridge18-cpu.github.io/english6/>

给六年级孩子用的英语同步练习站，内容对应 **人教PEP《英语》六年级上册（2026 新版）**。交互模仿多邻国式学习路径：按单元、按课本 Part A / B / C 和 Reading time 拆成小课，每课先听「知识讲解」，再做即时反馈练习。

## 功能

- **学习路径**：6 个单元 + Revision + 「过去式训练营」（附录 5 不规则动词），共 55 节小课，每单元一个 🏆 单元挑战（15 题，错 3 次以内通过）。
- **知识讲解**：每课中文讲解词汇、语法和句型，可一键朗读（中文用 zh-CN，英文自动切换 en-US）；重点句型、本课单词都能点读。
- **练习**：选择、听力、填空拼写、连词成句、配对 5 种题型，每题有解析；进度条只在答对时前进，答错的题会重新排进队列；连击奖励。
- **课文听读**：每篇课本对话 / 短文 / 歌曲逐句显示英文 + 中文，点句朗读、「朗读全文」逐句高亮、调速、隐藏中文；🎤 跟读：支持语音识别的浏览器（Chrome / Edge）会逐词打分，否则录音回放对比。
- **故事**：每单元 2 篇原创分级小故事 + 阅读理解题，以及课本 Reading time。
- **错题本**：答错自动收录，按 1/2/4/7/15 天间隔重复复习，复习不扣爱心、可恢复爱心。
- **激励**：经验值、爱心（每 30 分钟恢复 1 颗）、连续学习天数、连击、每日 3 个任务（按日期生成）、本周报告（7 天经验柱状图）、19 个成就。
- **家长中心**：每日学习时长上限、家长 PIN、导出 / 导入进度、清空进度、近 7 天学习记录。
- 进度只保存在本浏览器 `localStorage`，换设备请先在家长中心导出。

## 目录

```
index.html        页面外壳
css/style.css     样式
js/app.js         全部交互逻辑（纯 JS，无需构建）
data/book.js      数据（window.BOOK = …），页面直接加载
data/book.json    同一份数据的 JSON 版本
tools/            生成数据用的脚本和逐单元内容源文件（Python）
```

数据结构（`data/book.json`）：`units[]` 每个单元含 `words`（单词、音标、中文、课本页码、`req` 是否黑体“会用”词、`lvl2` 课标二级词、`past` 过去式）、`passages`（课文逐句：说话人 / 英文 / 中文）、`lessons`（讲解 `explain`、重点句 `key`、题目 `questions`）、`stories`、`song`、`expressions`（附录 4）、`grammar`；另有 `irregular`（附录 5）。

重新生成数据：在 `tools/` 下运行 `python3 build.py ..`（需要 pymupdf 和课本 PDF，路径见脚本）。只改题目或讲解时，编辑 `tools/content/u*.py` 后重新生成即可。
