# pip english · 六年级英语闯关站 v3.4 · PEP Grade 6

在线使用：<https://lightbridge18-cpu.github.io/english6/>

给六年级孩子用的英语同步练习站，内容对应 **人教PEP《英语》六年级上册（2026 新版）** 和 **六年级下册（2027 春）**。v3 按 Duolingo 的玩法全面重做：蜿蜒的学习路径、吉祥物「皮皮」、连胜 / 宝石 / 爱心 / 排行榜 / 任务 / 商店。

## v3 新玩法

- **课程切换**：顶栏左侧的课本按钮（📘 六上 / 📗 六下）。课本列表来自 `data/books.json`，每本书的进度分开保存。
- **学习路径**：每个单元一条蛇形路径 + 彩色单元横幅（📖 GUIDEBOOK 单元要点）；圆形 3D 关卡按钮，当前关卡跳动并显示 START，完成后变金色并显示等级；关卡之间有宝箱（送宝石），单元末尾是 🏆 单元挑战。默认按顺序解锁，可「跳到这里」做测试跳级；家长中心可一键解锁全部。
- **题型**：图片选词、点击配对（5 对）、单词块翻译（中→英 / 英→中）、听音点词（可切换键盘输入，含 🐢 慢速）、选词填空、完成对话、跟读口语（语音识别逐词高亮）、选择、听力、拼写、连词成句。可以「现在不方便听 / 说」跳过 1 小时。
- **反馈**：底部 CHECK 按钮→绿色 / 红色反馈面板（正确答案 + 解析 + 朗读），连对进度条发光，WebAudio 生成的音效，答错抖动，完成撒彩带，手机振动；课程完成页（经验、正确率、用时、连击奖励）和连胜页（本周日历）。
- **游戏系统**：每日经验目标（10/20/30/50）、爱心（5 颗，每 30 分钟恢复 1 颗，练习赚回，或用宝石补满）、宝石、商店（爱心补满、连胜冻结、双倍经验、皮皮装扮、主题）、每日 3 个任务 + 月度徽章、每周联赛（青铜→钻石，本地模拟的练习伙伴，前 5 晋级后 5 降级）、成就。
- **练习中心**：错题复习（间隔重复）、听力练习、口语练习、综合练习、单词练习、课文听读、故事、单词表。
- **家长中心**：学习时长上限、PIN、导出 / 导入（兼容 v2 备份）、解锁全部、无限爱心。
- 进度保存在本浏览器 `localStorage` 的 `e6.v3`（首次打开会自动把旧版 `e6.v2` 的进度迁移进六上，旧数据保留不动）。

## 目录

```
index.html          页面外壳
css/style.css       样式（Nunito 字体加载不了时自动用苹方 / 微软雅黑）
js/app.js           全部交互逻辑（纯 JS，无需构建）
data/books.json     课本清单（id、标题、数据文件）
data/book.json/.js  六年级上册数据（id: book）
data/g6down.json/.js 六年级下册数据（id: g6down）
tools/              生成上册数据用的脚本和内容源文件（Python）
```

加新课本：把同结构的 JSON 放进 `data/`，在 `data/books.json` 里加一项（`ready: true` 直接显示；不写 `ready` 时，打开课程菜单才探测文件是否存在）。

数据结构（`data/book.json`）：`units[]` 每个单元含 `words`（单词、音标、中文、课本页码、`req` 是否黑体“会用”词、`lvl2` 课标二级词、`past` 过去式）、`passages`（课文逐句：说话人 / 英文 / 中文）、`lessons`（讲解 `explain`、重点句 `key`、题目 `questions`）、`stories`、`song`、`expressions`（附录 4）、`grammar`；另有 `irregular`（附录 5）。

重新生成数据：在 `tools/` 下运行 `python3 build.py ..`（需要 pymupdf 和课本 PDF，路径见脚本）。只改题目或讲解时，编辑 `tools/content/u*.py` 后重新生成即可。

## v3.4 新功能

- **🎬 情景小剧场**（`#/scenes`、`#/scene/<id>`）：每个单元一个原创小短剧（六上 6 个 + 六下 4 个，每个 8 句、2–3 个角色：皮皮 Pip、米娅 Mia、露西 Lucy），用本单元的单词和句型。像动画片一样播放：插画缓慢推拉（Ken Burns）+ 交叉淡入、说话人气泡、英文字幕 + 可开关中文、自动下一句、暂停 / 重播 / 上一句 / 下一句。看完后三步：
  1. **🎤 跟读**（`#/scene/<id>/rep`）：逐句录音，AI 识别后逐词打分；没有 AI 次数时改为「听自己的录音 + 自评」。
  2. **🎭 角色扮演**（`#/scene/<id>/role`）：选一个角色，其他角色自动说，轮到你时录音（可选「挑战模式」隐藏英文），最后可以连起来听整场表演。
  3. **🤖 自由对话**：打开以本剧为话题的 AI 聊天。
  首页每个单元路径末尾有小剧场卡片，练习中心有「情景小剧场」列表。看完 +5 XP，跟读 +10~15 XP 💎5，角色扮演 +10 XP 💎5（重复练习给少量经验）。进度存在 `books.<id>.scenes`。
  插画：`scenes/<id>/<n>.webp`（AI 生成，统一的扁平卡通风格，≤80KB）；台词录音：`scenes/<id>/a/<n>.mp3`（edge-tts 女声：皮皮 Jenny 美音、米娅 Ana 美音童声、露西 Sonia 英音）。内容源：`tools/scenes_src.py` → `python3 tools/build_scenes.py` 生成 `data/scenes.json`；录音：`env -u HTTPS_PROXY -u https_proxy -u HTTP_PROXY -u http_proxy python3 tools/gen_scene_audio.py`。
- **🤖 和皮皮聊天**（`#/chat`、`#/chat/<场景或单元 id>`）：点 🎤 说英语、再点一下结束（最长 15 秒，iPhone Safari 录 mp4、安卓 / 微信录 webm），或点 ⌨️ 打字。服务器用 Groq 转写（whisper-large-v3-turbo），再由聊天模型（openai/gpt-oss-120b，备用 qwen/qwen3.8-27b）按儿童安全规则回复：只用 A1–A2 简单英语、每次 1–2 句 + 一个追问、温和地纠正（recast），并给一句中文小提示和 0–3 星评价。皮皮的回答用浏览器女声朗读（跟随美音 / 英音设置）。
- **🤔 讲讲我错在哪**：答错后的反馈面板和错题本里都有这个按钮，AI 用简单中文讲为什么错、正确答案为什么对；同一题同一答案的讲解缓存 90 天，再点不扣次数。
- **次数限制**（北京时间每天 0 点重置）：登录班级账号（班级码 + 昵称 + PIN）每天 AI 对话 10 次、讲解 20 次、跟读打分 60 次；没登录的按 IP 每天对话 3 次、讲解 3 次、跟读打分 10 次；另有按 IP 和全站的总量保护。页面上会显示剩余次数。录音上限 15 秒 / 1 MB。
- Groq API key 只存在服务器（Cloudflare Worker），从不发给浏览器。

## v3.3 新功能

- **🚩 报错**：每道题和讲解页都有「报错」按钮（答案不对 / 题目看不懂 / 发音不对 / 其他 + 备注），离线时先存本机，联网自动补发；家长中心可看本班报错。
- **真人女声朗读**：`audio/us/`（en-US-JennyNeural，单词 + 句子 + 讲解里的英文）和 `audio/gb/`（en-GB-SoniaNeural，单词），文件名 = 规范化文本的 FNV-1a 哈希，`audio/manifest.json` 列出已有的哈希；没有录音的句子自动退回浏览器朗读。重新生成：`node tools/audio_inventory.js && env -u HTTPS_PROXY -u https_proxy python3 tools/gen_audio.py`（需要 `pip install edge-tts` 和 ffmpeg）。Service Worker 只在播放时缓存音频（cache-first）。
- **🏁 期末冲刺**（`#/mock`）：30 题 / 20 分钟模拟卷，按听力、单选、填空、阅读与对话出题，不扣爱心，交卷出分（满分 100）和分项成绩，错题进错题本，保留成绩记录。
- **🎧 单词听写**（`#/dict`）：按单元或「错词」听写，可开关中文提示，大小写和空格不计较。
- **📍 这周学到哪**：首页 / 设置里选本周重点单元，首页定位并显示「本周重点」卡片，一键开始下一课。
- **📊 每周学习报告**：家长中心，最近 7 天学习分钟（只算正在操作的时间）、经验、小课、正确率、最常错的 10 个单词、模拟卷成绩，可打印。
- **🧑‍🏫 老师看板**（`#/teacher`，家长中心进入）：班级码 + 教师 PIN（第一次输入即设置，服务器只存哈希），看全班本周 XP、活跃天数、最近学习、全班最常错的单词和题（同步时上传匿名汇总）、报错列表。
- **班级榜**：本周榜（北京时间周一 00:00 清零，服务器计算）+ 总榜；服务器限制不合理的经验增长、需要 PIN 才能写入、同一账号 8 秒内只能同步一次。
- **👀 护眼提醒**：连续学习 10 / 20 / 30 分钟（可关闭）后，在一节课结束时提醒远眺 20 秒。
- **微信内置浏览器**：自动把口语题换成其他题型，提示「点右上角 ··· 在浏览器打开」，补充分享用的标题、描述和图标。
